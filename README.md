# Triple Espresso Coffee Shop

This is the second project of the Software Engineering program at TripleTen. It was created using HTML and CSS, based on the design brief.

## Project features

- Semantic HTML5
- Flexbox
- Positioning
- Flat BEM file structure
- A custom form
- CSS animation and transform

## Plan on improving the project

The web page could be improved with the addition of animated elements and dynamic background images. In the future, I would like to incorporate interactivity features for best user experience, such as: automated menus, a section dedicated to reviews and testimonials, and live chat for general inquiries.
